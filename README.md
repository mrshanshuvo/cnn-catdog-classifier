# CNN Cat Dog Classifier

A deep learning image classification project that uses a Convolutional Neural Network (CNN) to classify images as either cats or dogs.

## Features

* Cat and dog image classification
* CNN-based image recognition
* Image preprocessing
* Model training and validation
* Accuracy evaluation
* Prediction on new images
* Deep learning workflow using Python

## How It Works

```text
Input Image
     ↓
Image Preprocessing
     ↓
CNN Model
     ↓
Feature Extraction
     ↓
Classification
     ↓
Cat / Dog Prediction
```

## Tech Stack

* Python
* TensorFlow / Keras
* Convolutional Neural Network (CNN)
* NumPy
* Matplotlib
* Computer Vision

## Getting Started

Clone the repository:

```bash
git clone https://github.com/mrshanshuvo/cnn-catdog-classifier.git
cd cnn-catdog-classifier
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the training or prediction workflow provided in the project.

## Model Workflow

The project follows a standard image classification pipeline:

1. Load the dataset
2. Preprocess the images
3. Split data for training and validation
4. Build the CNN model
5. Train the model
6. Evaluate model performance
7. Predict new images
